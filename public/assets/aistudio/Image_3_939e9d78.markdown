## Brand & Style

This design system embodies the calculated elegance of modern developer tooling (evoking the clarity of Linear and Vercel in high-key light mode). It strips away superfluous ornamentation in favor of scannability, structural hierarchy, and typographical cadence.

### Target Audience
Engineering leads, technical founders, and product teams seeking a developer who builds with rigorous attention to detail, performance, and systematic craft.

### Emotional Response
- **Confidence & Rigor:** Communicates an obsession with code quality, precision, and reliable engineering.
- **Velocity:** Uncluttered layouts and high visual contrast make technical narratives immediately digestible.
- **Tactile Modernity:** Subtle borders, precise geometry, and focused color accents make interactive artifacts feel crisp and responsive.

### Design Movement
**Modern Technical Minimalism:** A synthesis of Swiss modernist layout logic and developer-centric utility. It leverages high-contrast typography, hairline borders, generous negative space, and disciplined electric blue interaction cues over decorative gradients or heavy drop shadows.

## Colors

The palette relies on stark, clean surfaces with deliberate, high-contrast ink and an authoritative electric blue accent for active, interactive, and syntactical states.

### Palette Architecture
- **Surfaces & Canvas:**
  - Base Background: `#FFFFFF` (Pure white for main stage, reading flow, and hero blocks)
  - Secondary Canvas: `#F8FAFC` (Ultra-subtle slate canvas to set off cards and code modules)
  - Surface Container: `#F1F5F9` (Component tracks, metadata badges, and inline code tags)
  - Hairline Border: `#E2E8F0` (Default perimeter line for structural separation)
  - Subtle Border Focus: `#CBD5E1` (Hovered frames and segmented controls)

- **Typography & Ink:**
  - Primary Ink: `#0F172A` (Slate 900 — Maximum readability for headers, primary copy, and key metrics)
  - Secondary Ink: `#334155` (Slate 700 — Descriptive paragraphs, system labels, and technical summaries)
  - Muted Ink: `#64748B` (Slate 500 — Captions, timestamps, meta tags, and placeholder copy)

- **Accents & States:**
  - Primary Interactive (Electric Blue): `#2563EB` (Primary CTAs, terminal prompts, link underlines, and active states)
  - Interactive Hover: `#1D4ED8` (Deepened blue for click states)
  - Accent Subtle: `#EFF6FF` (Focus halos, active list selections, and highlight fills)
  - Success State: `#059669` (Deployment live indicators, passing test badges)

## Typography

The typographic hierarchy couples the clean, geometric balance of `Inter` for prose and titles with `JetBrains Mono` for developer context (terminal outputs, code snippets, metadata, and status metrics).

### Application Rules
- **Negative Tracking on Headlines:** Tighten letter spacing on all display and headline sizes (`-0.02em` to `-0.03em`) to deliver the dense, precise feeling of technical UI.
- **Monospaced Micro-labels:** Metadata, commit hashes, version tags, and tech stack chips strictly use `label-sm` or `label-md` to provide structural rhythm alongside prose.
- **Reading Length:** Limit long-form case studies to a maximum width of `68ch` to maintain scannability.

## Layout & Spacing

The layout is built upon an 8pt base grid with a max-width constrained canvas (`1200px`) centered on viewport screens, preserving crisp vertical alignments and whitespace balance.

### Grid & Breakpoints
- **Desktop (1024px+):** 12-column fluid grid, `24px` (`1.5rem`) gutters, and dynamic margins auto-centering the `1200px` content container.
- **Tablet (768px – 1023px):** 8-column grid with `24px` gutters and `32px` (`2rem`) page margins. Sidebars collapse to inline sections.
- **Mobile (< 768px):** 4-column grid with `16px` (`1rem`) gutters and `20px` (`1.25rem`) horizontal margins. Multi-column project cards stack vertically.

### Rhythmic Discipline
- Nested elements within cards use `space-sm` (`8px`) or `space-md` (`16px`) gaps.
- Structural section padding relies on `space-xl` (`40px`) or multiplied variants (`80px` / `5rem` for major section divisions).

## Elevation & Depth

Visual hierarchy is articulated through hairline borders and subtle tonal layering rather than heavy drop shadows, reinforcing a light, technical UI canvas.

### Depth Mechanics
- **Ground Floor:** `#FFFFFF` or `#F8FAFC` base canvas with zero elevation.
- **Framed Layering (Hairline Borders):** Depth is primarily articulated via `1px solid #E2E8F0`. When an element requires elevation or hover, it transitions to border color `#CBD5E1`.
- **Subtle Surface Lift (Cards & Floating Panels):**
  - Ambient Shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.03)`
  - Elevated Popover/Flyout: `0 10px 15px -3px rgba(15, 23, 42, 0.05), 0 4px 6px -4px rgba(15, 23, 42, 0.02)` coupled with a hairline border `#E2E8F0`.
- **Active State Transition:** Hovering interactive cards drops the border tone to `#94A3B8` and triggers a microscopic translateY (-1px) accompanied by a diffused blue accent glow: `0 8px 20px -6px rgba(37, 99, 235, 0.08)`.

## Shapes

The design system maintains a consistent 16px (`1rem`) corner radius across primary structural containers and cards, balancing technical sharpness with modern software approachability.

### Radii Tokens
- **Containers & Project Cards (`rounded-lg`):** `16px` (`1rem`). Applied to code previews, project showcases, and main card wrappers.
- **Interactive Controls (`rounded`):** `8px` (`0.5rem`). Applied to buttons, inputs, segmented filter buttons, and search bars.
- **Badges & Micro-tags (`rounded-sm`):** `6px` (`0.375rem`). Applied to tech stack tags, status indicators, and keyboard shortcut chips.
- **Avatars & Pill Badges:** Full circular radius (`9999px`) reserved strictly for user profile avatars and "Available for work" status chips.

## Components

### Buttons
- **Primary Button:** Background `#0F172A`, text `#FFFFFF`, radius `8px`, font `Inter` 14px weight 500. On hover: background `#1E293B`. Active: `#334155`.
- **Secondary / Action Button (Electric):** Background `#2563EB`, text `#FFFFFF`, radius `8px`. On hover: `#1D4ED8`. Focus outline: 2px ring `#EFF6FF` with `#2563EB` offset.
- **Outline Button:** Background `#FFFFFF`, border `1px solid #E2E8F0`, text `#0F172A`, radius `8px`. Hover: background `#F8FAFC`, border `#CBD5E1`.

### Cards & Project Artifacts
- **Base Card:** Background `#FFFFFF`, border `1px solid #E2E8F0`, corner radius `16px`, padding `24px`.
- **Interactive Tech Card:** Same base with smooth transition on hover (`border-color: #94A3B8`, `box-shadow: 0 8px 24px -4px rgba(15, 23, 42, 0.06)`).
- **Featured Repository Card:** Includes top bar with monospaced repo meta (`JetBrains Mono`, 12px), middle canvas with architecture overview or preview frame, and bottom row with pill tags for stack tags and metric counters.

### Chips & Badges
- **Tech Stack Badge:** Background `#F1F5F9`, border `1px solid #E2E8F0`, text `#334155`, font `JetBrains Mono` 11px, radius `6px`, padding `4px 8px`.
- **Status Indicator Pill:** Background `#F0FDF4`, border `1px solid #BBF7D0`, text `#15803D`, corner radius `9999px`. Features a continuous pulsing 6px circle `#22C55E`.

### Code & Terminal Blocks
- **Window Frame:** Background `#F8FAFC`, border `1px solid #E2E8F0`, radius `16px`. Top header bar with three subtle grey window controls (`#CBD5E1`) and monospace file path in `#64748B`.
- **Code Container:** Monospace typography (`13px / 22px`), syntax highlighted against white/slate-50 background with active line highlight in `#EFF6FF`.

### Input Fields & Search
- **Input:** Background `#FFFFFF`, border `1px solid #E2E8F0`, text `#0F172A`, placeholder `#94A3B8`, radius `8px`, padding `10px 14px`.
- **Focus State:** Border `#2563EB`, box-shadow `0 0 0 3px rgba(37, 99, 235, 0.12)`.
- **Command Palette (`Cmd+K`):** Floating modal with subtle backdrop blur, search input at the top with inline monospaced hotkey chip (`Kbd`), and navigable list items below.

### Lists & Activity Feeds
- **Commit / Timeline List:** Connected vertical hair line (`#E2E8F0`) with 8px circular nodes. Hoverable items trigger `#F8FAFC` background fill with inset electric blue dot.
